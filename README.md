# vikramkumar.org

Source for [www.vikramkumar.org](https://www.vikramkumar.org), the personal site of Vikram Kumar, built with Jekyll and hosted on GitHub Pages.

- `index.md` holds the page content
- `_layouts/default.html` is the page template (head, SEO tags, nav, footer)
- `assets/css/style.scss` holds all styles
- `_config.yml` sets the site title, description, share image and plugins

Pushing to `master` publishes the site.
